# Scientific Notes — GitHub Pages

A lightweight static website with four main sections:

- Blog Index (`index.html`)
- Blog (`blog.html`)
- Books of Interest (`books.html`)
- About Me (`about.html`)

## Publish on GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose the branch-based publishing source (usually `main` / root).
5. Open `https://YOUR-USERNAME.github.io`.

## Add a new blog post

1. Duplicate `post-template.html`.
2. Rename it, e.g. `wgm-hexagonal-cavity.html`.
3. Edit its title, date, category, and content.
4. Add a link to the new page in `blog.html` and optionally `index.html`.
